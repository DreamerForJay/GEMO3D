Abstract

Monocular 3D vehicle detection must infer depth from a single image. The height of a detected 2D box follows the visible silhouette, so it differs from the projected height of the vehicle’s 3D centerline — a bias that changes with viewing angle, distance and vehicle shape. GEMO3D combines learned detection, classification and orientation with camera geometry, and corrects this bias with a vehicle-specific rank-1 projection-height ratio model estimated from the viewing angle and initial pinhole depth. The corrected depth drives 3D box reconstruction with ground-plane and reprojection constraints, without ground-truth depth at inference.

Method

1

Pinhole initialization

YOLOv11 detects the vehicle, a classifier picks its size prior H and Ego-Net estimates the viewing angle θ. The box height gives an initial depth.

Zraw = fy H / h2D
2

Projection-height ratio correction

The 2D box follows the silhouette, not the 3D centerline. A class-specific rank-1 SVD model predicts the ratio rc ≈ h2D / h3D,proj from θ and Zraw — see the model below.

Zcorr = Zraw · rc(θ, Zraw)
3

3D reconstruction

Back-projection places the box at the corrected depth, a ground-plane constraint fixes its bottom center, and reprojection aligns it with the 2D detection.

Core contribution

Rank-1 Projection-Height Ratio Model

Instead of regressing a depth error, GEMO3D models why pinhole depth is biased — the ratio between the detected box height and the ideal projected height of the 3D centerline — and compresses that ratio surface with a low-rank (rank-1) SVD.

Why a ratio, not an error?

The raw error is not a fixed offset: it grows with distance (Fig. 3) and depends on θ (Fig. 4). Because projected height is inversely proportional to depth, the scale-free ratio captures the bias directly:

r = h2D / h3D,proj

Zraw = fyH / h2D therefore over- or under-estimates depth by exactly this factor.

  1. 01

    Virtual data

    Blender renders each vehicle type over a grid of viewing angles θ and center depths. YOLOv11 gives h2D; projecting the 3D centerline gives h3D,proj.

  2. 02

    Ratio matrix

    For class c, ratios are arranged on the angle × depth grid:

    Rc(i, j) = rc(θi, Zj) ∈ ℝNθ×NZ
  3. 03

    Normalize & center

    Depth is mapped to ρc(Z) ∈ [−1, 1]. The per-angle mean bc(θ) is removed so the SVD models only the depth-dependent change:

    Xc = Rc − bc1T
  4. 04

    Rank-1 SVD

    Keeping only the first singular component gives a compact low-rank surface:

    Xc = UcΣcVcT ≈ σ1u1v1T
rc(θ, Z) = bc(θ) + ac(θ) · Cc(ρc(Z))
angle baselinemean ratio per angle angle amplitudeσ1u1 shared depth curvev1

bc(θ) is nearly flat, while |ac(θ)| changes strongly with direction: one shared depth curve, scaled per angle, reconstructs the whole ratio surface (manuscript Fig. 5).

At inference

Each class stores only Mc = {bc, ac, Cc, Θc, Zmin,c, Zmax,c} — three 1-D curves, interpolated. The predicted class, θpred and Zraw look up the ratio:

Zcorr = Zraw × rc(θpred, Zraw)

Ground-truth depth is used only to build the model offline, never at inference.
